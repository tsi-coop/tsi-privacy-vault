Erasure Job History

The job is a safety net, not the main path. A shred request completes in the request itself. A pass finishes interrupted drains, finalizes principals left in SHREDDING and shreds PARTIAL principals whose retention has ended, unless a legal hold is open. Interval is set with TSI_PRIVACY_VAULT_ERASURE_JOB_MINUTES. A manual pass is run with run_erasure_job by a SYSTEM_ADMIN. Run history older than 90 days is removed.
